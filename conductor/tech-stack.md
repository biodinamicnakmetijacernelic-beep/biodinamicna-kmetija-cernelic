# Tech Stack: Biodinamična kmetija Černelič

This document outlines the core technologies and significant libraries used in the development and deployment of the Biodinamična kmetija Černelič website.

## 1. Core Technologies

*   **Frontend Framework:** React (Version 19)
    *   A declarative, component-based JavaScript library for building user interfaces.
*   **Programming Language:** TypeScript
    *   A superset of JavaScript that adds static typing, enhancing code quality and maintainability.
*   **Build Tool:** Vite
    *   A fast, opinionated build tool that provides a rapid development experience for modern web projects.
*   **Content Management System (CMS):** Sanity CMS
    *   A headless, real-time CMS that allows for flexible content modeling and easy content delivery.
*   **Styling:** Tailwind CSS
    *   A utility-first CSS framework for rapidly building custom designs.
*   **Deployment & Hosting:** Netlify
    *   A platform for automated deployments, continuous integration, and serverless functions, used for hosting the website.

## 2. Key Libraries & Tools

*   **Animation:** Framer Motion
    *   A production-ready motion library for React, enabling fluid and engaging UI animations.
*   **PDF Generation:** jsPDF & jspdf-autotable
    *   Libraries for generating PDF documents directly from client-side JavaScript, potentially used for reports or printable content.
*   **Utility Functions:** Lodash (clonedeep, set)
    *   A modern JavaScript utility library delivering modularity, performance, and extra features.
*   **Iconography:** Lucide React
    *   A collection of customizable, open-source icons for React projects.
*   **Image Cropping:** React Easy Crop
    *   A component for cropping images with zoom and rotation features.
*   **Routing:** React Router DOM
    *   A standard library for routing in React applications, enabling navigation between different pages/views.
*   **Email Sending:** Resend
    *   An API for sending transactional emails, likely integrated for contact forms or order confirmations.
